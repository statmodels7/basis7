# Does This Basis Sum to One?

Whether the family is a partition of unity, which
[`check_basis`](https://statmodels7.github.io/basis7/reference/check_basis.md)
tests only for the families that claim it.

## Usage

``` r
basis_partitions_unity(basis)
```

## Arguments

- basis:

  An object inheriting from class `basis`.

## Value

`TRUE` or `FALSE`.
