# Legendre Polynomial Basis

`PolyBasis` is the S7 class of the Legendre polynomial bases that
[`poly_basis()`](https://statmodels7.github.io/basis7/reference/poly_basis.md)
returns. It adds no property to
[basis](https://statmodels7.github.io/basis7/reference/basis.md) and
exists as the class on which the Legendre methods dispatch. Each of
[`basis_eval()`](https://statmodels7.github.io/basis7/reference/basis_eval.md),
[`basis_deriv()`](https://statmodels7.github.io/basis7/reference/basis_deriv.md),
[`basis_int()`](https://statmodels7.github.io/basis7/reference/basis_int.md),
[`basis_gram()`](https://statmodels7.github.io/basis7/reference/basis_gram.md)
and
[`basis_colnames()`](https://statmodels7.github.io/basis7/reference/basis_colnames.md)
has an exact method registered here, so a Legendre basis does not use
finite differences. The Gram matrix above order zero is a Gauss-Legendre
quadrature that is exact for the polynomials involved.

## Usage

``` r
PolyBasis(
  basis_name = character(0),
  dimension = integer(0),
  lower = integer(0),
  upper = integer(0),
  basis_params = list()
)
```

## Arguments

- basis_name:

  A single string naming the family, printed by
  [`print.basis()`](https://statmodels7.github.io/basis7/reference/print.basis.md)
  and used by wrappers to build their own name. Its first two characters
  form the default column names of
  [`basis_colnames()`](https://statmodels7.github.io/basis7/reference/basis_colnames.md).

- dimension:

  The number of functions in the basis, a single integer of at least 1.
  Must be of storage mode integer.

- lower, upper:

  The endpoints of the interval on which the basis lives, or one
  endpoint per variable for a basis of several. Both must be finite and
  of the same length, and `lower[j] < upper[j]` must hold for every `j`.
  [`basis_nvar()`](https://statmodels7.github.io/basis7/reference/basis_nvar.md)
  returns their length.

- basis_params:

  A named list of whatever else the subclass needs: the knots and degree
  of a B-spline, the period of a Fourier basis, the marginal dimensions
  of a product.
  [`print.basis()`](https://statmodels7.github.io/basis7/reference/print.basis.md)
  shows it, abbreviating any numeric entry of more than four values.
  Defaults to an empty list.

## Value

An object of class `PolyBasis`, inheriting from
[basis](https://statmodels7.github.io/basis7/reference/basis.md), with
the same five properties, where `basis_params` holds `degree`. Call
[`poly_basis()`](https://statmodels7.github.io/basis7/reference/poly_basis.md)
instead of this class directly; it validates its arguments and fills in
`basis_name` and `basis_params`.

## The origin of the numbers

The polynomials are generated by the three-term recurrence \$\$(n+1)
P\_{n+1}(t) = (2n+1)\\ t\\ P_n(t) - n\\ P\_{n-1}(t),\$\$ on \\t \in
\[-1, 1\]\\, with \\P_0 = 1\\ and \\P_1 = t\\, and the variable shifted
from the basis interval by \\t = 2(x - \ell)/(u - \ell) - 1\\.

Derivatives come from the same recurrence differentiated,
\\P\_{n+1}^{(d)} = P\_{n-1}^{(d)} + (2n+1) P_n^{(d-1)}\\, so every order
is exact and follows the same formula; see
[`legendre_deriv()`](https://statmodels7.github.io/basis7/reference/legendre_deriv.md).
The integral uses \\\int P_n = (P\_{n+1} - P\_{n-1})/(2n+1)\\ and is
exact as well.

## Its `basis_params`

The list holds one entry, `degree`, which equals `dimension - 1` and is
the highest degree that the basis carries. The list holds no other
entry, because the interval and the count determine the polynomials.

## Examples

``` r
p <- poly_basis(dimension = 4)
S7::S7_inherits(p, PolyBasis)
#> [1] TRUE
p@basis_params$degree
#> [1] 3

# A Legendre basis has no numerical component.
basis_is_numerical(p)
#> basis_deriv   basis_int  basis_gram 
#>       FALSE       FALSE       FALSE 
```
