# Legendre Polynomial Basis

The S7 class of Legendre polynomial bases. Constructed by
[`poly_basis`](https://statmodels7.github.io/basis7/reference/poly_basis.md).

## Usage

``` r
PolyBasis(
  basis_name = character(0),
  dimension = integer(0),
  lower = integer(0),
  upper = integer(0),
  basis_params = list()
)
```

## Arguments

- basis_name:

  A short name for the family, used when printing.

- dimension:

  The number of functions in the basis, a positive integer.

- lower, upper:

  The endpoints of the interval the basis lives on.

- basis_params:

  A named list of whatever else the subclass needs.

## Value

An object of class `PolyBasis`. Use
[`poly_basis`](https://statmodels7.github.io/basis7/reference/poly_basis.md)
rather than calling the class directly.

## Details

The polynomials are generated by the three-term recurrence \$\$(n+1)
P\_{n+1}(t) = (2n+1)\\ t\\ P_n(t) - n\\ P\_{n-1}(t),\$\$ on \\t \in
\[-1, 1\]\\, shifted to the basis interval. Derivatives come from the
derivative of the same recurrence, so every order is exact and no order
is special, and the integral from \\\int P_n = (P\_{n+1} -
P\_{n-1})/(2n+1)\\ is exact as well.

## See also

[`poly_basis`](https://statmodels7.github.io/basis7/reference/poly_basis.md)

## Examples

``` r
p <- poly_basis(dimension = 4)
S7::S7_inherits(p, PolyBasis)
#> [1] TRUE
```
