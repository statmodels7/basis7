# Refuse Points Outside a Range, and Clamp Those On Its Edge

Refuse Points Outside a Range, and Clamp Those On Its Edge

## Usage

``` r
clamp_to_range(z, lo, hi, what)
```

## Arguments

- z:

  A numeric vector.

- lo, hi:

  The endpoints.

- what:

  A phrase naming the range, used in the error message.

## Value

`z`, clamped.
