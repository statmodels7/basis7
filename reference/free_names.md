# The Names of the Free Columns

Names the columns `null_space = "keep"` restores: `lin` for the linear
one, which is the only one at `order = 2`, and `poly2`, `poly3` and so
on for the higher powers an order above 2 leaves unpenalized.

## Usage

``` r
free_names(n)
```

## Arguments

- n:

  How many.

## Value

A character vector of length `n`.
